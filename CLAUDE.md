## Repository purpose

This is `flecherdev/flecherdev` — a GitHub **profile README repo**. Because the repo name matches the account username (`flecherdev`), GitHub renders its `README.md` directly on the user's GitHub profile page (https://github.com/flecherdev).

It is not a software project: there is no source code, package manifest, build system, linter, or test suite. The entire content of the repository is `README.md`.

## Working in this repo

- The only file to edit is `README.md`.

- There are no commands to run (no lint, test, or build steps apply here).
- Keep edits to standard GitHub-flavored Markdown, since it's rendered on the public profile page. Verify that any images, badges, or links referenced still resolve.
